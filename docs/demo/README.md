# IssuePilot video demonstration

**Presentation title:** IssuePilot — AI-Assisted Engineering Issue Triage | Architecture & Live Demo

**Video filename:** `IssuePilot-AI-Assisted-Engineering-Issue-Triage-Demo.mp4`

This demonstration walks through the independent IssuePilot portfolio proof of concept, including a local Java/Spring Boot/Vaadin UI, synthetic issue history, a human-reviewed Codex triage skill, and an in-app issue analysis.

The real-world production workflow described in the main README was co-developed by engineering managers and used email-triggered triage with Slack summaries. This public application and recording use independent code and synthetic data; they are not recordings or exports of the original employer system.

The MP4 must be uploaded separately using GitHub's web interface. It is not included in this text-only commit.
